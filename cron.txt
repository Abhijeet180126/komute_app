# Komute cron jobs

# Auto-complete rides past their scheduled arrival time (every 10 min)
*/10 * * * * /var/www/komute/venv/bin/python /var/www/komute/manage.py complete_rides >> /var/www/komute/logs/cron.log 2>&1

# Retention: biometric/OCR scrub + verification record expiry (item 1-3)
15 2 * * * /var/www/komute/venv/bin/python /var/www/komute/manage.py scrub_verification_data >> /var/www/komute/logs/cron.log 2>&1

# Retention: ride search log, 90 days (item 4)
30 2 * * * /var/www/komute/venv/bin/python /var/www/komute/manage.py purge_ride_search_log >> /var/www/komute/logs/cron.log 2>&1

# Retention: chat messages, 1 year after ride completed/cancelled (item 7)
# Must run BEFORE the completed/cancelled ride purges below, so messages
# are evaluated on their own clock before any cascade-delete from a ride purge.
0 3 * * * /var/www/komute/venv/bin/python /var/www/komute/manage.py purge_old_messages >> /var/www/komute/logs/cron.log 2>&1

# Retention: completed rides, 2 years after completion (item 5)
15 3 * * * /var/www/komute/venv/bin/python /var/www/komute/manage.py purge_completed_rides >> /var/www/komute/logs/cron.log 2>&1

# Retention: cancelled rides, 6 months after cancellation (item 6)
30 3 * * * /var/www/komute/venv/bin/python /var/www/komute/manage.py purge_cancelled_rides >> /var/www/komute/logs/cron.log 2>&1

# Retention: account deletion requests, ACCOUNT_DELETION_GRACE_DAYS (default 45)
# after the user confirms via the emailed link (item 8). Emails ADMIN_EMAIL a
# summary of any accounts purged in the run.
45 3 * * * /var/www/komute/venv/bin/python /var/www/komute/manage.py purge_deactivated_accounts >> /var/www/komute/logs/cron.log 2>&1

# Driver identity re-verification (ISSUES.md C2): reminder email
# DRIVER_REVERIFY_REMINDER_DAYS (10) before, then verification cleared after
# DRIVER_REVERIFY_DAYS (90). 14:00 UTC = 9-10 am Eastern, so reminders arrive in daytime.
0 14 * * * /var/www/komute/venv/bin/python /var/www/komute/manage.py expire_driver_verification >> /var/www/komute/logs/cron.log 2>&1
To install on the droplet:


crontab -e -u www-data
paste the block in, save, then confirm with crontab -l -u www-data.

Two things before you rely on this:

Test each new command with --dry-run first on the real server (e.g. python manage.py purge_cancelled_rides --dry-run) to sanity-check the counts before letting it actually delete rows.
